# Concept: one screen, one question

A simpler Zvonec, approved as a direction by the owner („Je to dobrý směr“) and refined step by step.

- `index.html` – the static mockups (open it from a local server rooted at the repo, so the tokens and
  fonts under `docs/` load). They use the real palette and type tokens, nothing else.
- `0*.png` – the screens as rendered (390 × 844 phone, 1440 × 900 desktop).

The idea: every screen answers one question and fits on one screen.

| Tab | Question | What is on it |
|---|---|---|
| Moje | When do I serve? | what waits for my answer (Můžu / Nemůžu on it), my confirmed duties, Kdy nemůžu |
| Obsazení (leaders) | Whom do we still need? | only events with something to do: a chip per missing role, who has not answered, clashes |
| Kalendář | What is happening? | one list by week; on a desktop the month with the open event beside it |
| Lidé | How do I reach someone? | search, A–Z, a call button on each row |

The event shows when, where, my duty and the names per team on one line each; roles, Osnova,
description and map are one tap further. Administration (templates, formats, places, access, settings,
public web) lives under the person's circle at the top right; the Více tab goes away. Data and logic stay
as they are – only the screens change.
